냠냠레시피 — 운영자 소개(교체용)
<h2>운영자 소개 · 편집 원칙</h2>
<p>냠냠레시피는 <b>아이와 요리 초보가 혼자 따라할 수 있는 레시피</b>를 삽화와 함께 정리하는 블로그입니다.</p>
<h3>누가 만드나요</h3>
<p>운영자(요리하는 고양이 셰프)가 <b>재료 계량·조리 시간·실패 사례를 직접 확인</b>해 글을 작성합니다. 모든 삽화는 블로그 전용으로 직접 제작합니다.</p>
<h3>검증 절차</h3>
<ol>
<li>재료와 분량을 실제로 조리해 확인합니다 (전자레인지 출력·팬 화력 기준 명시)</li>
<li>아이 혼자 하기 어려운 단계(칼·불·끓는 물)는 <b>🚨 표시</b>하고 보호자 동반을 안내합니다</li>
<li>알레르기·익힘 정도처럼 안전과 직결된 내용은 본문에 별도로 표시합니다</li>
<li>발행 후 오류 제보를 받으면 확인 후 수정하고, 수정 시점을 글 하단에 남깁니다</li>
</ol>
<h3>편집 원칙</h3>
<ul>
<li>과장·낚시 표현을 쓰지 않습니다 (예: "무조건", "100% 성공")</li>
<li>광고·제휴가 있는 경우 본문에 명시합니다</li>
<li>다른 곳의 레시피를 그대로 옮기지 않고, 계량·순서를 다시 정리해 씁니다</li>
</ul>
<h3>기준 시점</h3>
<p>각 글에 작성 시점(예: 2026년 10월 기준)을 표시합니다.</p>

월급쟁이 계산서 — 운영자 소개(교체용)
<h2>운영자 소개 · 편집 원칙</h2>
<p>월급쟁이 계산서는 <b>청약·세금·대출·연금을 숫자로 계산해 정리하는 블로그</b>입니다.</p>
<h3>누가 만드나요</h3>
<p>운영자(계산기맨)가 정부·공공기관 자료(국세청, 주택도시기금, 청약홈, 금융위원회)를 확인한 뒤 계산 예시를 직접 만들어 글을 씁니다.</p>
<h3>검증 절차</h3>
<ol>
<li>요율·한도·기한은 <b>기준 연도를 명시</b>하고 공식 자료로 확인합니다</li>
<li>모든 금액 예시는 계산 과정을 표로 남깁니다 (역산 가능)</li>
<li>제도가 바뀌면 기존 글을 수정하고 수정 시점을 표기합니다</li>
<li>확인이 어려운 항목은 "확인 필요"로 표시합니다 (추측해서 쓰지 않습니다)</li>
</ol>
<h3>편집 원칙</h3>
<ul>
<li>세무·법률 자문이 아닙니다 — 신고·신청 전 공식 창구에서 최종 확인을 안내합니다</li>
<li>과장·낚시 표현 금지, 수치의 근거를 항상 밝힙니다</li>
<li>특정 금융상품 추천(광고성)은 하지 않습니다</li>
</ul>
<h3>기준 시점</h3>
<p>각 글에 "2026년 10월 기준"을 표시하며, 개정 사항은 확인 후 반영합니다.</p>
